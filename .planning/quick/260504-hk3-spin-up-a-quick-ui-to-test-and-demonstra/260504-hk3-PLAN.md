### Task 2: Parse multi_doc_comparison.md for Tab 3

**File:** `app.py` (helper function)

**Action:** Add `_parse_comparison_md()` function that reads the markdown file and returns the summary table rows as a list of dicts. Use regex to extract the pipe-table rows — no external markdown library needed.

Pattern: lines starting with `| mq` → split on `|` → strip whitespace → map to dict keys.

```python
def _parse_comparison_md(path: str) -> list[dict]:
    rows = []
    with open(path) as f:
        for line in f:
            if line.startswith("| mq"):
                parts = [p.strip() for p in line.split("|")[1:-1]]
                if len(parts) >= 6:
                    rows.append({
                        "id": parts[0],
                        "question": parts[1],
                        "verdict": parts[2],
                        "graph_distinct_docs": parts[3],
                        "vector_covered": parts[4],
                        "graph_only": parts[5],
                    })
    return rows
```

**verify:** `_parse_comparison_md("data/eval/multi_doc_comparison.md")` returns 7 rows
