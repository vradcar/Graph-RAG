  <name>Task 1: Create unified LLM provider factory</name>
  <files>src/llm/provider.py, config/settings.yaml</files>
  <action>
Create `src/llm/provider.py` with:

1. A `build_instructor_client(provider: str) -> instructor.Instructor` function:
   - If provider == "groq": read GROQ_API_KEY from env, return `instructor.from_groq(Groq(api_key=key), mode=instructor.Mode.JSON)`
   - If provider == "openai": read OPENAI_API_KEY from env, return `instructor.from_openai(OpenAI(api_key=key))` (OpenAI supports tool mode natively, no need for JSON mode)
   - Raise ValueError for unknown provider or missing API key

2. A `get_llm_config() -> dict` helper that loads settings.yaml and returns `{"provider": ..., "model": ...}` from the `llm` section.

Update `config/settings.yaml` to add a comment showing the openai alternative:
```yaml
llm:
  provider: groq  # or "openai"
  model: moonshotai/kimi-k2-instruct-0905  # groq model; for openai use e.g. "gpt-4o-mini"
```

Dependencies to add to requirements.txt: `openai>=1.30.0` (the `instructor` library already supports it).
  </action>

  <done>provider.py exists, imports succeed, get_llm_config returns provider and model from settings.yaml</done>
