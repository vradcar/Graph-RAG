<task type="auto">
  <name>Task 1: Re-ingest T9 with provenance and capture baseline counts</name>
  <files></files>
  <action>
    1. Verify graph_items.json exists: `ls -lh data/processed/graph_items.json`. If missing, run `python -m src.pipeline.ingest --input data/raw/products_sample.json` to regenerate (Phase 1 does NOT modify ingest.py — just invokes the existing CLI).

    2. Run the provenance-aware loader with reset:
       ```
       python -m src.graph.neo4j_loader \
         --reset \
         --doc-id t9_install_guide \
         --doc-title "T9 Smart Thermostat Installation Guide" \
         --doc-sku T9 \
         --doc-source-url "honeywellhome.com/t9-install-guide" \
         --input data/processed/graph_items.json \
         --verify
       ```

    3. Capture the verify output (node count, edge count, nodes-by-label, edges-by-type) into a temp file `.planning/phases/01-schema-provenance-foundation/_t9_baseline.txt`. This is the v1.0+provenance baseline that Phase 2's INGEST-05 non-regression test will compare against.

    4. Run the audit Cypher (via `cypher-shell` or `session.run`) and capture results:
       - `MATCH ()-[r]->() WHERE type(r) <> 'MENTIONED_IN' AND r.source_doc IS NULL RETURN count(r) AS missing` → expect 0
       - `MATCH (d:Document) RETURN d.doc_id, d.title, d.sku` → expect one row with t9_install_guide
       - `MATCH (n) WHERE n.source_docs IS NULL AND NOT n:Document RETURN count(n) AS no_provenance` → expect 0
       - `MATCH (n) WHERE NOT n:Document RETURN count(n) AS entities, count((n)-[:MENTIONED_IN]->(:Document)) AS mentions` (or equivalent) — every entity should have at least one MENTIONED_IN.

    5. Run the loader a SECOND time (without --reset) and capture verify output again. Compare to first run: node count and edge count must be IDENTICAL. Confirm source_docs[] for any sampled node is still length 1 (idempotency).

    Append the audit results and idempotency comparison to `_t9_baseline.txt`.
  </action>
  <verify>
    <automated>grep -E "missing.*0|missing AS 0|no_provenance.*0" .planning/phases/01-schema-provenance-foundation/_t9_baseline.txt && echo "AUDIT_PASS"</automated>
  </verify>
  <done>
    T9 graph re-ingested with provenance.
    `_t9_baseline.txt` contains: verify output (run 1), audit Cypher results (all 0 for missing/no_provenance), verify output (run 2) showing identical counts.
    Audit query for null source_doc returns 0.
    :Document {doc_id: 't9_install_guide'} exists exactly once.
  </done>

    2. Run: `MATCH (d:Document) RETURN d`. Expected: exactly one :Document node displayed, with properties doc_id="t9_install_guide", title, sku="T9", source_url, ingested_at, first_ingested.

    3. Run: `MATCH (n)-[r:MENTIONED_IN]->(d:Document) RETURN n, r, d LIMIT 25`. Expected: a star-shaped subgraph with the :Document at the center and entities (Thermostat, Accessory, etc.) connected via MENTIONED_IN.

    4. Run: `MATCH (a)-[r]->(b) WHERE type(r) <> 'MENTIONED_IN' RETURN r LIMIT 5`. Click a relationship to inspect properties. Expected: every edge has a `source_doc` property equal to "t9_install_guide".

    6. Run: `MATCH ()-[r]->() WHERE type(r) <> 'MENTIONED_IN' AND r.source_doc IS NULL RETURN count(r)`. Expected: 0.
