## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Silent null-MERGE | `merge_node_with_provenance` with missing node_id silently merges all null-keyed nodes together | advisory | Fixed: CR-01 adds `raise ValueError` guard — do not remove this guard |
| Silent edge drop | Missing endpoint nodes caused `load_edges` to increment `loaded` without writing the edge | advisory | Fixed: CR-02 adds `RETURN count(r)` and raises on 0 — preserve this pattern in any future edge-write helpers |
| Silent MENTIONED_IN skip | `MATCH (d:Document)` inside a node-merge query silently skips if Document doesn't exist | advisory | Fixed: CR-03 raises ValueError — always call `merge_document` (committed transaction) before ingesting nodes |
